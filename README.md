# 桌边美术馆 · ArtDesk

让 Windows 桌面定时换一幅名画，再用中文认识这幅画。

本项目配合 **John’s Background Switcher（JBS）** 更换壁纸，提供离线中文画库、作品来源、搜索、分类、收藏和最近展示记录。打开介绍前，会核对壁纸文件、图片缓存和作品记录；无法确认时会明确提示，避免把另一幅画的介绍配到当前桌面。

**[下载最新完整 Windows 压缩包](https://github.com/sxc1295/artdesk/releases/latest)**。朋友使用请下载 `ArtDesk-v1.0.0-Windows.zip`；GitHub 自动生成的 `Source code` 压缩包只有源码，不包含画作图片。

## 开始使用

需要 Windows 10 / 11、系统自带 Windows PowerShell 5.1 和 Microsoft Edge。不需要安装 Python 或编程工具。

1. 下载完整 ZIP，右键选择“全部解压缩”，放到你有写入权限、以后不会随意移动的文件夹，例如“文档”中的 `ArtDesk`。不要放进 `Program Files`，不要在压缩包内直接运行。
2. 只想看画：双击 `Open-ArtDesk.cmd`，程序会在 Edge 独立窗口打开中文画库。没有配置 JBS 时，“当前画作”可能显示无法确认，点击“浏览全部画作”即可。
3. 想自动换壁纸：从 [JBS 官方 Windows 页面](https://johnsad.ventures/software/backgroundswitcher/windows/) 安装软件，至少启动一次，让它生成设置文件。
4. 双击 `Install-ArtDesk.cmd`。程序会备份 JBS 设置，把本包 `images` 文件夹设为画库，设定每 4 小时换画、完整显示画面并使用模糊背景，并创建桌面的“ArtDesk 名画介绍”快捷方式。
5. 等待或通过 JBS 手动换一张画，再双击桌面快捷方式查看对应介绍。以后可以在 JBS 中自行调整换画间隔。

安装会替换 JBS 的本地图片文件夹列表和换画后的命令。已有的开机启动选项和非文件夹图片来源保持原样，其他壁纸软件和 Windows 计划任务不会被自动禁用。非画库来源出现时，程序会显示无法确认当前作品。如果已有其他程序也会换壁纸，请自行保留一个换画程序，避免相互覆盖。

脚本仅对当前运行进程使用执行策略参数，不修改电脑的长期 PowerShell 执行策略。完整包未做商业代码签名；如电脑的单位管理策略阻止脚本运行，请遵守管理员要求。

## 画库与介绍

首版公开画库包含 **395 幅**，涵盖中国绘画、日本绘画与版画、欧洲古典、印象派与后印象派、现代艺术等类别。每幅保存作品编号、原始标题、中文资料、馆藏页面、图片许可和文件校验值。

公开版按原目录中明确的 CC0 / 公共领域许可记录筛选；原私人画库中许可记录不完整的 38 幅没有收入。中文介绍与欣赏提示是整理文字，核验程度写在各作品的来源说明中；部分作品仅有基础资料，未逐幅核实全部艺术史细节。图片许可与软件 MIT 许可分别适用，详见 [第三方来源说明](THIRD_PARTY_NOTICES.md)。

页面离线可用，点击博物馆原页和中文搜索链接时才需要联网。放大图使用适合浏览的缩略图；完整图片在 `images` 文件夹中。

## 使用时需要知道

- 介绍页是打开时的快照。桌面换画后，重新双击快捷方式可更新当前作品。
- “最近看过”记录已核对的壁纸展示；浏览详情不会伪装成换过桌面。最多保存 200 条。
- 收藏保存在 Edge 本机浏览器中。移动文件夹、换浏览器配置或清理浏览数据可能导致收藏不能继承。
- 当前作品识别主要面向单画面及 JBS 的完整图像加模糊背景模式。多屏不同画作、拼贴等布局可能无法唯一确认，页面会保留画库浏览功能。
- 本程序不自动下载新的画作，也不自动补充中文介绍。
- 公开包不包含作者的桌面记录、收藏、账户凭据、个人路径或 JBS 程序本体。

## 退出与恢复

双击 `Uninstall-ArtDesk.cmd` 恢复本程序安装前备份的 JBS 设置，并清理属于此安装的快捷方式。图片和使用记录保留；确认不再需要后可以自行删除整个解压文件夹。卸载不会移除 JBS 本体。

请先恢复再移动文件夹。安装后如又手动改过 JBS 设置，恢复旧备份也会覆盖这些后续变化；卸载前会另存当前配置，方便需要时找回。记录与备份保存在 `local-state` 中。多份 ArtDesk 安装不要同时接管同一个 JBS。

## 常见问题

**提示找不到 JBS 或设置文件。** 请从官网安装并启动一次，然后退出设置窗口再安装本项目。非标准安装路径可通过 PowerShell 的 `Install-ArtDesk.ps1 -JbsExecutable "完整路径"` 指定。

**提示图片缺失。** 检查下载的是完整 Windows ZIP，并已全部解压。源码 ZIP 不包含图片。安装后不要改动 `images` 内的文件名或内容。

**桌面有画，介绍却说无法确认。** 等换画完成后重新打开；检查有没有另一个程序覆盖壁纸，或是否使用了多屏拼贴模式。保留这个提示比显示错误介绍更可靠。

## 源码开发

源码仓库包含 PowerShell 程序、HTML 模板、395 条作品资料和验证脚本。较大的原图及生成的离线页面资源放在 GitHub Release，避免每次克隆下载全部图片。

要在源码目录运行，先从完整 Release 中复制 `images/` 和 `gallery-data.json`。随后可执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\ArtDesk.ps1 -NoOpen
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\Test-ArtDesk.ps1
```

修改作品目录后，开发者可使用 Python 3.10+ 和 Pillow 重建离线缩略图：

```powershell
python -m pip install -r requirements-dev.txt
python tools/build_gallery.py
```

图片必须与目录中的 SHA256 校验值一致。重建脚本不从互联网下载图片；新图片需要先核实来源与许可，再补齐目录。发布工具 `tools/package_release.py` 只收录明确列出的项目文件，不会打包运行记录、JBS 备份或凭据。
